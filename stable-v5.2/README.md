# Stable v5.2 project archive

These 12 Base64 parts contain the complete curated stable v5.2 Scorpion project snapshot (199 files), including its binary PNG assets. They deliberately exclude the full Mega Drive ROM and all reverted v5.3.x wall-parallax experiments.

From the repository root run:

```bash
python3 restore_project.py
```

The restore script verifies SHA-256 `1e534df005bd62337f3de8062ec64846d69f3a9a218d54d1c27ef6d49f0a7fed` before extracting.
